# CodingColor

Piccola web app realizzata per il laboratorio di **TPSIT (4BINF)** per comporre e visualizzare colori in formato **RGB**: inserendo tre valori tra `0` e `255` e un'etichetta opzionale, aggiorna i canali `R / G / B` e mostra l'anteprima del colore generato insieme alla data del giorno.

## Struttura del progetto

```text
CodingColor/
├── index.html    # Struttura semantica della pagina (input, badge R/G/B, anteprima)
├── styles.css    # Stile a scheda centrata, badge e transizioni del riquadro colore
├── script.js     # Logica JavaScript commentata (data, validazione, array colori, reset)
└── README.md     # Panoramica del progetto
```
